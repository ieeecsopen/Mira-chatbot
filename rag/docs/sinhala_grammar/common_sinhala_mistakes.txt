සිංහල භාෂාවේ නිතර සිදුවන ව්‍යාකරණ සහ භාවිත දෝෂ

------------------------------------------------------------
1. "අදහසක් නැතිව" vs "අදහසක් නැතිව"
   වැරදි: අදහසක් නැති ව 
   නිවැරදි: අදහසක් නැතිව

2. "ඉතාමත්" vs "ඉතාම"
   වෘත්තීය භාවිතයේ නිවැරදි: ඉතාම

3. "සමහරවිට" vs "සමහර විට"
   දෙකම භාවිතා වන නමුත් වෘත්තීය භාවිතය: "සමහරවිට"

4. "නෙවෙයි" vs "නොවේ"
   වෘත්තීය: "නොවේ"
   සාමාන්‍ය: "නෙවෙයි"

5. "මට පුළුවන්" vs "මට පුළුවන්නම්"
   වෘත්තීය: "මට පුළුවන්"

6. Spoken Sinhala → Formal Sinhala
   - "උබලා" → "ඔබලා"
   - "හරිම" → "ඉතා"
   - "ඉස්සෙල්ල" → "පළමුව"
   - "මොකද" → "කாரணය කුමක්ද?"

------------------------------------------------------------
ක්‍රියා පද සහ කාල දෝෂ

7. "මම ගියා" vs "මම ගියෙමි"
   සාමාන්‍ය: ගියා
   වෘත්තීය/අධ්‍යාපනික: ගියෙමි

8. "ඔහු යනවා" vs "ඔහු යයි"
   වෘත්තීය වර්තමාන කාල: "යයි"

9. "ඔවුන් කතා කරලා" vs "ඔවුන් කථා කළහ"
   වෘත්තීය: "කථා කළහ"

------------------------------------------------------------
නිතර වැරදි විශේෂණ භාවිත

10. "අවධානය යොමු කරන්න" vs "අවධානය යොමු කරනු ඇත"
11. "හොඳම" (superlative) vs "හොඳ" (simple adjective)

------------------------------------------------------------
අනවශ්‍ය redundant පද

12. "අත්‍යවශ්‍ය අවශ්‍ය" → ද්විත්ව භාවිත (වැරදි)
13. "පූර්ණයෙන්ම සම්පූර්ණයි" → අනුපූරණ පදයි

------------------------------------------------------------
අශ්‍රිත/අශ්‍රිත නොවන නිපාත දෝෂ

14. "මිස" vs "වෙත" vs "සඳහා"

15. "නිසා" vs "එබැවින්"
   - හේතුව: නිසා
   - ප්‍රතිඵල: එබැවින්

------------------------------------------------------------
බහුවචන දෝෂ

16. "ගුරු තුමන්ලා" → "ගුරුතුමාණන්"
17. "විද්‍යාලයන්" → "විද්‍යාල"

------------------------------------------------------------
අසම්මත වචන

18. "ඉගෙනුම" → "ඉගෙනීම"
19. "සිසු සමාජිකයින්" → "සිසුන්"

------------------------------------------------------------
හෝමෝෆෝන / අර්ථ සමාන දෝෂ

20. "අය" vs "අයට"
21. "ඇත්ත" vs "අත්ව"
22. "පහසු" vs "පහසුව"

------------------------------------------------------------
නිතර වැරදි වාක්‍ය නිර්මාණ

23. "ඔබට අවශ්‍ය ද?" → වෘත්තීය
24. "මට හරිද?" → සාමාන්‍ය, වැරදි නොවේ
25. "කරන ලදී" vs "කළ යුත්තේ"
26. "අයදුම් පත්‍රය පුරවන්න" (correct)
    "අයදුම් පත්‍රය පුරවන්නෙ" (incorrect)

------------------------------------------------------------
අධ්‍යාපනික / දේශීය භාවිත දෝෂ

27. "ප්‍රථමික" vs "මුල්"
28. "අදාළ" vs "අලුත්"

------------------------------------------------------------
Punctuation (Spoken → Formal)

29. "..." → “…” (proper ellipsis)
30. ", හැබැයි," → ", නමුත්,"

------------------------------------------------------------
Singlish → Sinhala Correct

31. "mokada" → "මොකක්ද?"
32. "hari hari" → "හරි"
33. "mage yaluwa" → "මගේ යාලුවා"

------------------------------------------------------------
Technical Sinhala Error Patterns

34. "කම්පියුටරය" → "කාම්පියුටරය" (informal)
   Correct: "පරිගණකය"

35. "නෙට්වර්ක්" → "ජාලය"
